# StarLink-By-QuantumAstra
🌐 StarLink Studio – Trusted Bridge for Celebrities, Influencers, Brands & Organizers
🚩 Problem

Brands and organizers face difficulty in finding the right influencers/celebrities for campaigns and events:

Brands get mismatched or spammy proposals.

Influencers receive non-serious or unverified requests.

Organizers lack a secure and transparent booking process.

The missing elements are trust, proof of work, and data-backed decisions.

💡 Our Solution

StarLink Studio is a demo service platform designed as a trusted bridge between influencers/celebrities and brands/organizers.
It showcases talent directories, portfolios, campaign analytics, testimonials, and booking flows to enable safe, transparent, and effective collaborations.

✨ Features
🔑 Core Website Sections

Hero + Loader: Preloader animation (loader.mp4) followed by a professional landing screen.

Talent Directory: Cards (cards.png) showcasing influencers with filters by niche, budget, and platform.

Hover Previews: On hover, quick popups show previous works, collaborations, and promotions.

Works & Portfolio: Influencer work samples categorized into Fashion, Fitness, Tech, Beauty, Gaming, etc.

Case Studies & Stats: Graphical data (graphs.png + stats.png) displaying campaign outcomes and growth metrics.

Testimonials: Video background (customer-section.mp4) with authentic client/creator quotes.

Final CTA: Ripple-effect styled button to drive brand sign-ups and bookings.

📊 Analytics & Stats

To build trust and credibility, we included a stats dashboard using graphs.png and stats.png visuals:

Network Size: Influencers onboarded over time.

Campaign Volume: Completed campaigns per year.

Audience Reach: Total unique audience reached across campaigns.

Engagement Metrics: Average engagement rate per campaign.

Trust Signals: Verified profiles %, dispute resolution %, on-time deliverables %.

🛠 Tech Stack

HTML, CSS, JavaScript (vanilla, single-file structure).

CSS transitions and keyframes for animations.

LocalStorage/sessionStorage for state handling (preloader, newsletter modal).

Custom SVG/Canvas + provided assets for charts and stats.

🚀 How to Run Locally

Clone this repository or download the files.

Open index.html in any modern browser.

Assets are inside /assets. Replace with your own if needed.

Content (influencers, works, stats) can be edited inline in the HTML/JS sections.
